Issue 3 2026-09-28 Week of Sep 22–28, 2026 6 top stories

This week in malware

Welcome to Virus Watch Weekly #3. Research for this issue was pulled from public reporting on Monday, Sep 28, 2026 (America/Denver). This week’s theme is malware that leans on AI — for deciding what to do after it infects a PC, for remote phone control, and for running commands on hijacked servers — plus a ClickFix stealer that blinds security tools with a vulnerable AMD driver, a fresh Oracle PeopleSoft extortion wave using the SideEye backdoor, and a new ransomware crew that threatens to wipe backups.

Top Stories

ClosedQuorum: Windows malware that lets AI models vote on the next attack move

High
CLOSEDQUORUM (aka ClosedQuorum)
In plain English

Researchers found a new Windows program that, after it lands on a PC, asks several public AI chat services what to do next — steal passwords, hide inside another program, or stick around after reboot — then follows the majority vote with no human typing commands. Stolen logins and crypto-wallet files can be sent to the criminals over Discord. You are unlikely to see this tomorrow in every inbox, but it shows attackers are starting to automate the “what should I do on this computer?” step. Keep devices patched, use a password manager with unique passwords, and treat unexpected installers as untrusted.

Cisco Talos (Sep 22), discovered via its CAIRN toolkit and covered by BleepingComputer, describes CLOSEDQUORUM as a Go-based Windows implant that delegates post-compromise tactical decisions to a panel of commercial LLMs (DeepSeek, Qwen, Mistral, Google Gemini). Models vote among constrained actions (steal, inject, persist, move); ties prefer DeepSeek. The steal path runs LSASS dumping, Chromium/Firefox credential theft, and MetaMask/Exodus/Ethereum wallet extraction; inject uses process hollowing or Early Bird APC; persist includes Run key, scheduled task, and WMI. Results go to an operator Discord webhook (AES-256-GCM, date-derived key). Talos has not confirmed broad in-the-wild deployment; public builds use placeholder API keys/webhook. Talos frames it as the first publicly documented Windows implant to use multi-model LLM voting as C2-style tasking.

Platforms: Windows
How it spreads: Operator-delivered custom builds (distribution model assessed as credentials-as-a-service); delivery vector for victims not publicly confirmed in-the-wild
Source: Cisco Talos / BleepingComputer

RemControl: Android banking malware sold as a service, fake TVTap app ads

High
RemControl (operator tracked as UNKK; possible Medusa banking-trojan link)
In plain English

Fake ads and lookalike Google Play pages for a TV streaming app trick people into installing RemControl on Android phones. Once you grant the Accessibility permission it asks for, it can put fake bank login screens over real apps, watch your screen, and steal PINs and one-time codes. Stick to the real Google Play store, decline Accessibility access for apps that don’t need it for real accessibility help, and keep Play Protect on.

BleepingComputer (Sep 23) covering Group-IB research: RemControl is a new Android malware-as-a-service active since at least May 2026 (samples from July) delivered via malvertising impersonating the TVTap IPTV app, including geofenced Italian campaigns and Meta Pixel tracking suggestive of Meta ad abuse. A VPN-style service blocks Google Play traffic to hinder Play Protect. With Accessibility granted it shows full-screen banking phishing overlays, streams the UI tree/screenshots, records input, performs remote gestures, captures pattern-lock coordinates across major OEMs, and blocks uninstall/factory-reset paths. Encrypted C2 material is pulled from Telegram; exposed FastAPI docs on a C2 proxy revealed overlay/credential endpoints. Targets include Europe (Italy, France, Spain, Poland, Portugal), Canada, and Middle East markets. Russian-language overlay HTML and a shared identifier lead Group-IB to track the operator as UNKK with a suspected Medusa banking-trojan connection.

Platforms: Android
How it spreads: Malvertising / fake Google Play pages (TVTap IPTV lure) → sideloaded APK → Accessibility abuse
Source: BleepingComputer / Group-IB

Carbonato: worm-like malware hijacks open Docker servers with an AI agent

High
Carbonato (Hermes Agent persona GH0ST)
In plain English

Servers that leave Docker’s remote control open to the internet without a password are being taken over by malware called Carbonato. It spreads like a worm to other open Docker hosts, sets up secret remote access, and installs an AI helper that can run commands and hunt for passwords and API keys when the criminals ask over Telegram. If you run Docker at home or work: never expose the Docker API (port 2375) to the public internet, and require login on any registry you use.

BleepingComputer (Sep 24) covering ThreatDown (Malwarebytes) research: Carbonato targets Docker daemons with unauthenticated API on port 2375, launches a privileged container, opens reverse SSH with operator keys, reports via Telegram, and persists via cron, systemd timers, rc.local, and OpenRC. It installs the Hermes Agent framework with a GH0ST persona (overwriting SOUL.md); Hermes interprets Telegram tasks, writes/runs shell commands, and returns results (AI API keys, SSH credentials, tokens). Worm-like scanners every five minutes pull the implant from an unauthenticated Docker registry (~60 repos, 4.3 GB observed). Evidence spans Oct 2024–Aug 2026; possible Costa Rica operator nexus; IoCs include GH0ST persona, CARBONATO_API_KEY, Telegram traffic, reverse SSH toward AS262145.

Platforms: Linux Docker hosts (exposed daemon API)
How it spreads: Unauthenticated Docker API (port 2375) → privileged container → worm scan of adjacent networks
Source: BleepingComputer / ThreatDown (Malwarebytes)

Lunex / Psychedelic Stealer: fake Cloudflare ClickFix + AMD driver blinds security tools

High
LunexStealer (aka Psychedelic Stealer) on the Lunex MaaS platform
In plain English

Hackers broke into ordinary websites and added a fake “Cloudflare security check” that tells visitors to paste a Windows install command. That installs a password stealer sold as Lunex. Before it steals browser logins and crypto wallets, it loads a buggy AMD driver so security software keeps running but can’t see clearly. Never paste “verification” commands from a webpage into Run or PowerShell — close the tab and open the real site yourself.

Ontinue (Sep 24) with The Hacker News follow-up (Sep 26) and earlier Arctic Wolf Labs ClickFix reporting: Ukrainian-speaking users hit via compromised legitimate sites injecting fake Cloudflare CAPTCHA / ClickFix that launches msiexec for a malicious MSI. LunexLoader escalates via CMSTPLUA COM (UAC bypass), loads AMD Radeon PDFWKRNL.sys (CVE-2023-20598) for BYOVD kernel-callback zeroing against a ~20-driver security hit list (leaves EDR processes running but blind), then deploys LunexStealer (psychedeliclove.exe). Stealer hits seven Chromium browsers, five desktop and four extension wallets; persists via Run key, hidden task psychedelicloveUtils, and a Chrome/Edge Native Messaging Host (com.lunex.explorer) backed by embedded PowerShell that survives binary deletion. Ontinue mapped 28 Lunex panels across 13 countries (up from six in June); Russian-language panel UI; financially motivated CIS-aligned MaaS assessment.

Platforms: Windows
How it spreads: Compromised websites → fake Cloudflare ClickFix → malicious MSI → LunexLoader BYOVD → LunexStealer
Source: Ontinue / The Hacker News

ShinyHunters: new PeopleSoft mass-exploitation wave drops SideEye backdoor

High
SideEye backdoor (+ JSP web shells; UNC6240 / ShinyHunters)
In plain English

Google and Mandiant say the ShinyHunters extortion crew is again breaking into companies that run Oracle PeopleSoft by slipping past some firewall rules with a small URL trick. After getting in, they plant remote-control tools — including a Windows backdoor called SideEye that can steal passwords and open a secret remote channel — then steal data and threaten to leak it. Big companies using PeopleSoft should apply Oracle’s fix for CVE-2026-35273, check for odd web shells, and prepare for ransom emails if something looks wrong.

SecurityWeek (Sep 28) reporting Mandiant / Google Threat Intelligence (UNC6240 / ShinyHunters): a new mass-exploitation wave against Oracle PeopleSoft CVE-2026-35273 uses URL-encoded ‘%50’ in /PSEMHUB paths to bypass WAF/reverse-proxy rules that match literal paths before decoding. Campaign expanded beyond education into agriculture, government, healthcare, IT, technology, and transportation. Persistence via complementary single-line JSP web shells; SideEye backdoor on Windows for browser/app credential theft, file/process management, reverse shell and reverse proxy; Neo-reGeorg for tunneling and MeshCentral for remote management. Actors abuse PeopleSoft/WebLogic service accounts for app data, configs, and DB connection strings. Pattern remains data-theft extortion via leak site. Prior June wave hit 100+ customers (e.g. University of Nottingham, NAIC, Nissan).

Platforms: Oracle PeopleSoft / WebLogic environments; Windows servers (SideEye)
How it spreads: Unauthenticated RCE via CVE-2026-35273 (WAF-bypass encoding) → web shells → SideEye / tunneling tools → data theft extortion
Source: SecurityWeek / Mandiant & Google Threat Intelligence

n0n ransomware: new gang threatens to destroy backups if you don’t pay

High
n0n
In plain English

A new ransomware group calling itself n0n showed up mid-September and quickly listed more than a dozen alleged victims. Besides stealing files, they claim they will encrypt or wipe backups so the company cannot recover without paying. They often start with stolen employee passwords. Businesses should use phishing-resistant MFA, keep backups offline or immutable, and watch for odd admin logins.

Infosecurity Magazine (Sep 24) summarizing CyberXTron research: n0n first observed Sep 18, 2026; by Sep 22 its Tor leak site listed 13+ victims across ~10 countries (US heavy; also Vietnam, Uzbekistan, Brazil, Sweden, Luxembourg). Double extortion plus explicit threats to encrypt/destroy backups and shadow copies. Sector mix led by financial services (~23%), then technology, retail, and education (~15% each), plus healthcare, defense, and professional services. Initial access assessed as compromised credentials from third-party infostealers, then privilege escalation and admin tooling for staging. Several countdown timers already expired with data published, suggesting some non-payment. Recommended controls: MFA on external access, restrict VPN/RDP exposure, least privilege, segmentation, monitor lateral movement, isolate backups.

Platforms: Enterprise Windows networks (credential-driven; specifics of encryptor vary by affiliate reporting)
How it spreads: Stolen infostealer credentials → privilege escalation / admin tools → data theft + backup-destruction threats + leak site
Source: Infosecurity Magazine / CyberXTron
