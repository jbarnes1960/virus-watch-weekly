This week in malware

Welcome to Virus Watch Weekly #2. Research for this issue was pulled from public reporting on Monday, Sep 21, 2026 (America/Denver). This week brought encryptionless ransomware via hijacked Active Directory rules, a new ClickFix-delivered RAT that hides its C2 on a blockchain, a sneaky npm supply-chain campaign, a hijacked entertainment brand used for malvertising, and a government advisory on Iranian spyware aimed at activists and journalists.

Top Stories

PAYLOAD ransomware: hijack the office network rules, skip the encryptor

High
PAYLOAD (GPO-based encryptionless extortion + ESXi/Linux encryptor)
In plain English

Attackers who already had admin-level access to a company network created a fake "company policy" that hit every Windows PC at once. Desktops showed ransom messages, wallpapers changed, and local admin accounts were turned off — without locking personal files with the usual ransomware encryptor. Stolen company data was leaked on the dark web. For businesses: lock down domain-admin accounts with phishing-resistant MFA, and alert whenever a new policy is linked at the top of the domain.

Kaspersky GERT (published Sep 21) detailed an April 2026 incident at a Middle East manufacturing firm. After obtaining domain-admin-equivalent access (likely via phishing and VPN/remote login that looked like legitimate IT), operators authored a malicious Active Directory Group Policy Object named PAYLOAD, linked at the domain root (GUID {C897F2C7-C2AC-4E6F-BF48-58036FF29E79}). Through that single GPO they delivered ransom notes, hijacked desktop wallpaper and lock screens, enforced a logon banner, and disabled the local Administrator account across domain-joined Windows workstations — without deploying a Windows encryptor or encrypting workstation files. A separate "win Firewall Off" GPO disabled Windows Firewall. An ESXi/Linux PAYLOAD encryptor was found on Linux servers; data exfiltration from file servers was later published on the dark web. Impact often appeared after reboot when cached policies applied. Kaspersky frames this as part of a broader "encryptionless extortion" trend.

Platforms: Windows domain-joined workstations (GPO disruption); ESXi/Linux servers (encryptor observed)
How it spreads: Compromised privileged AD credentials → malicious domain-root GPO + optional ESXi/Linux PAYLOAD encryptor; data theft for leak-site pressure
Source: Kaspersky Securelist / press

ChainScript RAT: ClickFix fake Spotify installers + Polygon C2 rotation

High
ChainScript (aka ComponentTask33 / UpdateDigital / HostShared / OrchidViolet66)
In plain English

Fake "fix your Spotify/Zoom/Teams" web pages trick people into running an installer that secretly installs remote-control malware. Once on the PC, criminals can run commands, take screenshots, dig through crypto wallets, and stay connected even if their servers move. Never paste commands from a website into Run, PowerShell, or Terminal, and only install apps from official stores or vendor sites.

The Hacker News (Sep 21) covering Blackpoint Adversary Pursuit Group research describes a previously undocumented JavaScript RAT delivered via ClickFix-style lures. Victims are steered to download a malicious Windows MSI (e.g. ComponentTask33-…msi) disguised as Spotify; msiexec installs a Node.js runtime and launches the ChainScript agent through hidden PowerShell and VBScript stages under %LOCALAPPDATA% paths that look Microsoft-related. Persistence uses a scheduled task with a Registry Run key fallback. The implant speaks WebSockets to C2 and supports interactive CMD/PowerShell, file ops, screenshots, payload deployment, crypto wallet enumeration (desktop apps and browser extensions), remote JS execution, self-update, and self-removal. C2 discovery uses an EtherHiding-style Polygon smart contract so operators can rotate WebSocket backends without rebuilding the implant.

Platforms: Windows
How it spreads: ClickFix social engineering → malicious MSI (fake Spotify/Zoom/Teams) → Node.js agent
Source: The Hacker News / Blackpoint

Malicious npm packages hide loaders in normal library code

High
indexed-btree (+ 9 related npm packages)
In plain English

Fake coding libraries on npm looked legitimate and skipped the usual "install script" traps, so security tools that only watch installs missed them. The bad code woke up later when the app used the library, then phoned home with machine details. Developers who used indexed-btree or the related packages should rotate secrets and rebuild from clean backups — and not trust install-time scans alone.

BleepingComputer (Sep 20) reported Checkmarx findings on an npm campaign centered on indexed-btree, a typosquat-style lookalike of sorted-btree that reached ~2 million weekly downloads. The package avoids preinstall/install/postinstall scripts (bypassing npm v12 lifecycle-script approvals) and instead hides a loader inside BTree.prototype.set(), which fires at runtime when called with a specific key and loads obfuscated sharedLoad.min.js. Post-execution behavior includes collecting host details (arch, hostname, CPU, memory, uptime), exfiltrating via hardcoded Slack and Telegram channels, and polling an Ethereum Sepolia smart contract for C2 / second-stage payload material (X25519 → AES). Operators can wipe traces by deleting files and removing the malicious trigger. Nine additional related packages (including btree-core with ~1.95M downloads) were removed from npm; attackers maintained fabricated GitHub histories to look legitimate.

Platforms: Node.js / developer workstations and CI environments
How it spreads: npm dependency confusion / impersonation → runtime method trigger (not install scripts)
Source: BleepingComputer / Checkmarx

PasteSwitch: hijacked HBO Max Reddit ads push ClickFix stealers

High
PasteSwitch (MacSync, AMOS, Amatera, AnimateClipper, ZigClipper)
In plain English

Criminals took over HBO Max’s verified Reddit account and ran about 108 fake ads in two days. The ads sent people to lookalike download pages that told them to paste a "fix" command into Terminal (Mac) or Run/PowerShell (Windows) — which installed password- and wallet-stealing malware. Verified badges don’t mean an ad is safe; open the real HBO Max or vendor site yourself, and never paste commands from an ad.

Malwarebytes (Sep 15) summarizing Hudson Rock and ADAMnetworks research: attackers compromised the verified u/hbomax Reddit account and served ~108 malicious ads over ~48 hours in mid-September. Ads promoted fake AI tools, developer software, and macOS utilities, plus HBO Max lookalike download sites. Pages used ClickFix prompts to get victims to paste commands into macOS Terminal or Windows Run/PowerShell. Researchers named the delivery operation PasteSwitch. Observed macOS payloads included MacSync and Atomic macOS Stealer (AMOS) plus fake crypto wallets for seed-phrase theft; Windows routes delivered Amatera Stealer (often in-memory) and clipboard clippers AnimateClipper and ZigClipper. Ad mix included HBO Max lures plus OpenAI Codex and fake disk-utility themes. Reddit paused the ads and investigated after reports.

Platforms: macOS and Windows
How it spreads: Compromised verified Reddit advertising → ClickFix paste-command lures → stealers/clippers
Source: Malwarebytes / Hudson Rock

Chosen Brick: Iranian spyware against activists and journalists

High
Chosen Brick (CHOSEN BRICK)
In plain English

Western agencies warn that Iranian state hackers have been using malware called Chosen Brick since at least 2025 to spy on people they see as opponents — including activists and journalists. It steals contacts, emails, and social-media messages from Windows PCs, which can help track someone’s movements. If you think you might be a target, keep devices updated, be wary of unexpected app messages with download links, and contact your IT team or local authorities if something looks wrong.

A Sep 15, 2026 joint advisory from the UK NCSC, US FBI, and Netherlands AIVD (covered by The Register and published via IC3) describes CHOSEN BRICK, a malware family used by Iranian state cyber actors against individuals worldwide (including UK, US, and Netherlands) since at least 2025. Observed infections are Windows-only. Capabilities center on collecting contacts, emails, and social-media messages to enable movement tracking and repression of dissidents, activists, and journalists. Victim details have appeared on pro-Iranian leak sites, raising personal-safety concerns. Delivery has involved social messaging apps. Agencies urge organizations whose staff may be targeted to circulate guidance for personal as well as corporate devices, and to involve IT providers for forensic review if execution is suspected.

Platforms: Windows (personal and corporate endpoints)
How it spreads: Social messaging / targeted social engineering toward individuals of interest to Iranian intelligence
Source: FBI / NCSC / AIVD (via The Register)
