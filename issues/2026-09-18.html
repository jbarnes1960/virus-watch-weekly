Issue 1 2026-09-18 Week of Sep 14–18, 2026 6 top stories

This week in malware

Welcome to Virus Watch Weekly #1. Research for this issue was pulled from public reporting on Friday, Sep 18, 2026 (America/Denver). The past week was heavy on ransomware affiliates, supply-chain social engineering, and newly documented stealers and crimeware frameworks. Below are six cited stories from Kaspersky, Huntress, Cisco/Talos coverage, Brevo/BleepingComputer, LastPass/Delphos Labs, and CISA/ConnectWise advisories.

Top Stories

MovieReaper: modular malware via poisoned movie torrents

High
MovieReaper (HEUR:Trojan.Win64.Agent.gen)
In plain English

Criminals poisoned popular movie download links so people who thought they were grabbing a film instead installed spyware. Once on the computer, the malware can spy on files and give attackers remote access. Stick to legal streaming and treat unexpected .exe files from torrents as dangerous.

Kaspersky GReAT (Sep 17) detailed a previously unknown multi-stage crimeware framework dubbed MovieReaper. Attackers compromised the shared torrent-file repository itorrents.org so trackers serving magnet links delivered a malicious .torrent instead of the requested film (including lures named after The Odyssey). The loader uses anti-sandbox tricks, pulls shellcode over HTTP, resolves a second C2 address via Solana blockchain account data, then deploys modules for UAC bypass, persistence (masquerading as ProgramData\…\Telemetry\msedge.exe), and a file-manager implant with ~21 remote filesystem commands. Hundreds of victims across multiple countries were identified; the campaign has been active since at least mid-August 2026.

Platforms: Windows (64-bit)
How it spreads: Compromised public torrent file repository → malicious torrents disguised as popular movies → user executes .exe loader
Source: Kaspersky Securelist

Settra ransomware: MeshAgent persistence and anti-recovery TTPs

High
Settra
In plain English

Settra is ransomware that locks a company’s files and demands payment to unlock them. The attackers also try to wipe recovery options and event logs so IT teams have a harder time restoring systems without paying. Strong VPN and password hygiene help block the usual way they get in.

Huntress (Sep 17) published analysis of two Settra ransomware incidents (July retail/consumer services; September manufacturing). Settra was first observed around June 2026. In both cases the encryptor was named after the victim domain plus _win64.exe, dropped RESTORE_FILES.txt notes, and encrypted files with .locked or .locked_wip extensions. Operators installed MeshAgent RMM for persistence, cleared Windows event logs, disabled WinRE (reagentc /disable), used diskpart against recovery partitions, and in one case overwrote free space with cipher /w. The September case also showed BYOVD (gdrv.sys). Public reporting has previously tied Settra initial access to VPNs and compromised credentials.

Platforms: Windows (enterprise endpoints)
How it spreads: VPN / credential compromise (reported); post-compromise MeshAgent RMM + ransomware executable
Source: Huntress

Cisco FMC flaws abused for Qilin ransomware and espionage clusters

High
Qilin (via UAT-11988) + state-linked clusters
In plain English

Serious bugs in Cisco’s firewall management tools let outsiders break in without proper credentials. Once inside, attackers stole data, turned off security tools, and in some cases deployed ransomware. Organizations running these products needed to patch quickly—delay left networks wide open.

Cisco Talos and follow-on coverage (around Sep 10–11) described three post-compromise activity clusters on Secure Firewall Management Center (FMC) instances exploiting CVE-2026-20079 (auth bypass, CVSS 10.0) and CVE-2026-20316 (low-privilege login). Cluster UAT-11988 used living-off-the-land FMC tooling for recon, tunneling, credential theft, security-tool termination, and Qilin ransomware deployment. CISA added CVE-2026-20079 to KEV with a Sep 12 federal patch deadline. Organizations that delayed interim hotfixes remained exposed while a fuller hardening update rolled out the week of Sep 14.

Platforms: Cisco Secure Firewall Management Center (network infrastructure → downstream Windows/enterprise)
How it spreads: Exploitation of unpatched FMC web-interface vulnerabilities (unauthenticated / low-priv remote access)
Source: The Hacker News

Brevo supply-chain ClickFix hits ~100k customer websites

High
ClickFix / KongTuke-related loaders + WordPress backdoor plugin
In plain English

Hackers briefly hijacked trusted Brevo marketing widgets so visitor sites showed fake “are you human?” pages. Those pages tricked people into copying and running commands on their own computers. The vendor fixed the breach, but sites that embed those widgets should check for leftover backdoors.

On Sep 14, attackers used a stolen long-lived Cloudflare API key hardcoded in Brevo source to deploy a malicious Cloudflare Worker for ~5.5 hours. The Worker injected fake “Cloudflare verify you are human” ClickFix pages into brevo.com, sibforms.com, and embedded JS (forms, Conversations widget, SDK loader) used by customers. Visitors were tricked into pasting/running clipboard commands; on WordPress admin sessions the script tried to install a malicious “Web Media Optimizer”-style plugin. Sansec estimated ~100,000 sites may have been in the blast radius. Brevo revoked the key and published a post-mortem; residual backdoors on customer WP sites remain a concern.

Platforms: Web visitors (esp. Windows via ClickFix); WordPress sites embedding Brevo widgets
How it spreads: Compromised CDN/API key → edge injection into vendor JS → social-engineering ClickFix + optional WP plugin backdoor
Source: BleepingComputer

Rapuncel infostealer pushed via fake LastPass GitHub repos

High
Rapuncel (+ Alinubx.sys EDR-killer driver)
In plain English

Fake GitHub pages posed as LastPass and other password apps to lure people into downloading malware. The software steals saved logins from browsers and tries to shut off antivirus so it stays hidden. Only install password tools from official websites, never from random search results.

BleepingComputer (Sep 18) reported an ongoing campaign uncovered by LastPass and Delphos Labs: SEO-optimized fake GitHub repositories impersonating LastPass Authenticator and dozens of other brands. Download buttons redirect to ZIP payloads (inflated up to ~148MB) that abuse a renamed legitimate vsdbg.exe to sideload a malicious DLL. The chain deploys the previously undocumented Rapuncel infostealer plus a Microsoft-signed kernel driver (Alinubx.sys) capable of disabling a large set of AV/EDR products. Rapuncel steals browser data (including Chrome app-bound encryption bypass via injection) and persists as a Windows service that re-kills security tools after reboot. Assessed with moderate confidence as related to BoryptGrab / Cruciferra PUROSANGUE crypter.

Platforms: Windows
How it spreads: SEO + fake GitHub repos impersonating popular software → sideloaded installer
Source: BleepingComputer

ScreenConnect CVE-2026-84869 actively exploited (worm-like clients)

High
Rogue ScreenConnect clients / VBScript chain (CVE-2026-84869)
In plain English

A flaw in ScreenConnect remote-support software let attackers push malware onto PCs during help sessions. Rogue or compromised support clients could transfer and run files without the usual confirmations. Update ScreenConnect clients promptly and be cautious about who you allow to connect for remote help.

CISA added ConnectWise ScreenConnect CVE-2026-84869 to KEV (reporting around Sep 11–16). The critical client flaw (CVSS 9.9) can allow file transfer and execution through an active remote session without proper authorization/host confirmation. Huntress documented worm-like behavior: socially engineered rogue clients push a four-stage VBScript chain (1.vbs–4.vbs) to connected hosts during sessions. Patch: ScreenConnect 26.6.5+; temporary mitigation is disabling TransferFiles permissions. Servers are not directly affected, but host clients and access agents must be updated/reinstalled.

Platforms: Windows hosts running ScreenConnect clients (cloud and on-prem deployments)
How it spreads: Active support/access sessions + rogue/modified clients; social engineering to install unauthorized clients
Source: BleepingComputer / CISA

Quick Hits

  • CISA confirmed (Sep 15 coverage) that ransomware gangs are exploiting VMware vCenter CVE-2026-59310 (CVSS 9.8, unauthenticated RCE in Syslog server) — already in KEV since mid-August; Broadcom fix shipped July 29.
  • MovieReaper’s use of Solana account data for C2 discovery is another reminder that blockchain-backed dead-drops complicate sinkholing.
  • Settra operators misspelled the Windows Defender operational log channel in one clear-logs routine — a small DFIR gift when Defender logs survive.
  • Brevo’s root cause was a long-lived Cloudflare API key in source with full-account permissions — rotate CDN/API keys and prefer short-lived scoped tokens.
  • If you use Brevo widgets/forms: audit WordPress for unauthorized plugins and assume visitors during the Sep 14 UTC window window may have seen ClickFix lures.
